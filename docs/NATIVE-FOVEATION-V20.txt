from qualified NR callers. New lists binding a learned root signature start

recorded. Captured state is qualified explicitly; merely knowing a root/PSO
without its arguments is insufficient. Retained root references prevent
object-address reuse from identifying an unrelated root as a known caller.
Detailed argument capture remains restricted to qualified caller lists.

If a recording is temporarily incomplete, an existing blended crop history
is retained for recovery instead of evicted for a plain replacement. That
recording uses the normal provider path, resets stale histories and reports
a specific recovery reason. This does not bypass compute-state validation.
Feathering, release-to-apply settings, reduced center resolution, proxy-safe
NR calls, binding restoration and fence-based crop lifetime remain enabled.
